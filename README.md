# 疾风卡丁车 — PopKart 风格竞速游戏

一款在**手感**与**画面**上全面模仿《泡泡卡丁车》(PopKart / KartRider) 竞速模式的网页卡丁车游戏。
纯原生 HTML5 Canvas 实现（Mode-7 伪 3D 渲染），零依赖、零外部资源，所有美术与音效均为程序原创生成，不含任何原作版权素材。

## 怎么玩

直接用浏览器打开 `index.html` 即可。

| 按键 | 功能 |
|---|---|
| `↑` / `W` | 加速（倒计时抢油门可触发**完美起步**） |
| `↓` / `S` | 刹车 / 倒车 |
| `←` `→` / `A` `D` | 转向 |
| `Shift` | **漂移**（积攒集气条，攒满获得一管 N₂O，最多存 2 管） |
| `Ctrl` / `空格` | **氮气喷射**（漂移结束瞬间接喷射 = **双喷**） |
| `Esc` | 暂停 |

## 还原的泡泡卡丁车核心机制

- **漂移集气 → N₂O 喷射**：低抓地甩尾滑行积攒集气条，满槽兑换氮气
- **双喷 / 断位漂移小喷**：漂移收尾自带小喷，0.45s 窗口内接氮气触发强化双喷
- **起步加速**：倒计时精准踩油门获得完美起步加速
- **加速带、撞墙减速、出赛道减速、车辆碰撞推挤**
- 3 条主题赛道（绿荫村庄 / 冰封雪谷 / 黄金沙城）× 3 圈竞速，6 车同场（5 名 AI 带漂移、氮气与橡皮筋平衡）
- 经典 HUD：圆盘速度表、集气条、N₂O 储存槽、实时小地图、圈数/名次、计时与最速圈、结算排行榜
- 特效：漂移火花与烟雾、持久轮胎痕、氮气火焰、速度线、信号灯倒计时、逆行警告
- WebAudio 程序合成引擎声、漂移声、喷射声与 BGM
