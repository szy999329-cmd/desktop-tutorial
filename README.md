# 疾风卡丁车 — PopKart 风格竞速游戏

一款在**手感**与**画面**上全面模仿《泡泡卡丁车》(PopKart / KartRider) 竞速模式的网页卡丁车游戏。
**WebGL 真 3D 渲染**（Three.js，已内置于 `lib/`，无需联网），起伏地形、上下坡物理、立体车模与场景；所有美术与音效均为程序原创生成，不含任何原作版权素材。

## 怎么玩

直接用浏览器打开 `index.html` 即可。

| 按键 | 功能 |
|---|---|
| `↑` / `W` | 加速（倒计时抢油门可触发**完美起步**） |
| `↓` / `S` | 刹车 / 倒车 |
| `←` `→` / `A` `D` | 转向 |
| `Shift` | **漂移**（积攒集气条，攒满获得一管 N₂O，最多存 2 管） |
| `Ctrl` / `空格` | **氮气喷射**（漂移结束瞬间接喷射 = **双喷**） |
| `Esc` | 暂停 |

## 还原的泡泡卡丁车核心机制

- **漂移集气 → N₂O 喷射**：低抓地甩尾滑行积攒集气条，满槽兑换氮气
- **双喷 / 断位漂移小喷**：漂移收尾自带小喷，0.45s 窗口内接氮气触发强化双喷
- **起步加速**：倒计时精准踩油门获得完美起步加速
- **加速带、撞墙减速、出赛道减速、车辆碰撞推挤**
- 3 条主题赛道（绿荫村庄 / 冰封雪谷 / 黄金沙城）× 3 圈竞速，6 车同场（5 名 AI 带漂移、氮气与橡皮筋平衡）
- **真 3D**：第三人称追尾相机（冲刺 FOV 变化）、地形起伏与坡道物理、车轮滚动与前轮转向、漂移侧倾/坡道俯仰、3D 树木/雪松/仙人掌/起点拱门/远山、天空穹顶与立体云
- **精致车模**：金属车漆（环境反射）、镀铬鼻尖/排气/轮毂、金色五辐轮圈与刹车盘、大灯尾灯（刹车点亮）、碳纤维底盘与前铲、双层定风尾翼、赛车服车手与镜面头盔
- **氮气变形**：喷射瞬间机甲式展开——尾翼抬升外扩、侧翼板张开、排气管伸长、鼻锥前移露出旋转涡轮核心、全车能量灯带/轮圈光环/车底光晕点亮（变形机械音效）
- **车库 360° 展示**：主菜单进入暗色展厅，发光展台上旋转看车，实时换色、一键变形演示
- **霓虹拖尾**：漂移时后轮拖出黄橙光带（满集气转红），氮气喷射拖出青蓝能量带
- 经典 HUD：圆盘速度表、集气条、N₂O 储存槽、实时小地图、圈数/名次、计时与最速圈、结算排行榜
- 特效：漂移火花与烟雾、持久轮胎痕、氮气火焰、速度线、信号灯倒计时、逆行警告
- WebAudio 程序合成引擎声、漂移声、喷射声与 BGM

## 自动相似度检测

`SIMILARITY_REPORT.md` 由检测工具自动生成，对标泡泡卡丁车竞速模式逐项打分（当前 **99.0%**）：

```bash
# 1. 无头浏览器实机行为测试（Playwright 实际驾驶验证漂移/集气/氮气/双喷等手感）
NODE_PATH=$(npm root -g) node tools/behavior-test.mjs

# 2. 生成相似度报告（静态特征扫描 + 行为实测结果加权评分）
node tools/similarity-check.mjs
```

无法做到 100% 一致的部分（原作版权美术、数十条赛道与联机内容、桥梁隧道等立体结构）在报告的"已知差异"一节中如实列出。
